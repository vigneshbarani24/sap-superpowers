# Industry: Fashion & Apparel

## Business Characteristics
- Seasonal collections with 4-8 buying cycles per year
- Size/color/style variant management (grid articles)
- Rapid markdown cycles (full price → promotional → clearance)
- Global sourcing with complex lead times
- Returns handling (high return rates in e-commerce)

## Key SAP Modules
| Module | Fashion-Specific Features |
|--------|-------------------------|
| **MM** | Grid articles (size/color matrix), AFS (Apparel and Footwear Solution) |
| **PP** | Cut-make-trim planning, fabric utilization optimization |
| **SD** | Pre-order / at-once order processing, allocation management |
| **EWM** | Value-added services (labeling, pressing, gift wrapping) |
| **FI** | Royalty accounting, markdown accounting |
| **CO** | Collection profitability, style-level margin analysis |

## Key Processes
1. **Design → Sourcing → Production → Distribution → Retail → Markdown → Clearance**
2. **Pre-order cycle:** Collection planning → Buyer appointments → Order consolidation → Production commitment
3. **Allocation:** Available inventory → Allocation by store cluster → Replenishment → Inter-store transfer
4. **Markdown:** Full price sell-through analysis → Markdown optimization → Clearance → Write-off
