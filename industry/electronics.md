# Industry: Electronics & High-Tech

## Business Characteristics
- Rapid product lifecycles (6-18 months)
- Configure-to-Order (CTO) / Build-to-Order (BTO) manufacturing
- Serial number tracking from production to end-of-life
- Component obsolescence management
- Global supply chain with contract manufacturing (EMS/ODM)

## Key SAP Modules
| Module | Electronics-Specific Features |
|--------|------------------------------|
| **PP** | Discrete manufacturing, CTO configuration, SMT line integration |
| **MM** | Component lifecycle management, AVL (Approved Vendor List), consignment |
| **SD** | Serial number management, RMA processing, warranty tracking |
| **QM** | Component qualification, first article inspection, environmental testing |
| **PM** | Equipment maintenance for clean room / SMT lines |
| **CO** | Product cost estimate with component price volatility |

## Key Processes
1. **Design → Prototype → NPI → Mass production → Distribution → EOL**
2. **CTO/BTO:** Order → Configuration → Component reservation → Assembly → Test → Ship
3. **RMA:** Return → Diagnosis → Repair/Replace → Retest → Reship
4. **Obsolescence:** Component EOL notification → Last-time buy → Redesign trigger

## SAP Industry Solutions
- SAP S/4HANA for High-Tech
- SAP Product Lifecycle Management

## Compliance & Regulatory
- RoHS / WEEE (substance restrictions, e-waste)
- REACH (chemical substances in electronics)
- Conflict minerals (SEC, EU due diligence)
- Export controls (EAR, ITAR for dual-use)
- Energy efficiency labeling (Energy Star, EU EcoDesign)
