# Industry: Steel & Metals

## Business Characteristics
- Process manufacturing with variable yields and grades
- Catch weight and characteristic-based valuation
- Long lead time production (melting → casting → rolling → finishing)
- Quality certificates (MTR — Mill Test Reports) mandatory
- Scrap management and recycling

## Key SAP Modules
| Module | Steel-Specific Features |
|--------|------------------------|
| **PP** | Campaign planning, heat management, characteristic-dependent routing |
| **MM** | Catch weight, grade management, scrap procurement |
| **QM** | Mill Test Report generation, chemical analysis, mechanical testing |
| **SD** | Characteristic-based pricing, excess/shortage tolerances |
| **CO** | Heat-level costing, yield variance, scrap credit |
| **PM** | Furnace/mill maintenance, refractory management |

## Key Processes
1. **Order → Heat planning → Melting → Casting → Rolling → Finishing → Testing → Shipping**
2. **Quality:** Chemical analysis → Mechanical testing → MTR generation → Customer approval
3. **Yield management:** Planned vs. actual yield → Grade allocation → Scrap classification

## Compliance & Regulatory
- ASTM/EN material specifications
- Mill Test Report (EN 10204 3.1/3.2)
- Carbon emissions trading (EU ETS)
- Scrap metal handling regulations
