# Country: Netherlands

## Tax System
- **VAT (BTW):** Standard 21%, reduced 9%, zero-rated 0%
- **ICP (Intracommunautaire Prestaties):** Intra-EU transaction reporting
- **SAP config:** Tax procedure TAXNL

## E-Invoicing
- **Peppol** — preferred e-invoicing network (mandatory for B2G)
- **UBL-OEBL** (Dutch UBL profile) for e-invoicing format
- **Digipoort** gateway for government submissions

## Banking & Payments
- **SEPA** SCT/SDD — primary payment method
- **iDEAL** — common for B2C (increasingly B2B)
- **Dutch IBAN** format: NL## BANK 0123456789
- **Payment format:** SEPA XML pain.001/pain.008
- **Bank statement:** camt.053

## Date & Currency
- **Date format:** DD-MM-YYYY
- **Currency:** EUR (€)
- **Decimal notation:** 1.234,56

## Regulatory
- **GDPR (AVG)** — Dutch GDPR implementation
- **Dutch Accounting Standards (RJ)** or IFRS for listed companies
- **Tax audit file (XAF)** — standard audit file for tax authorities (SAF-T NL)
- **UBO register** — beneficial ownership transparency

## Key SAP Transactions
- SAF-T NL export
- Peppol integration for e-invoicing
