# Country: Germany

## Tax System
- **VAT (Umsatzsteuer):** Standard 19%, reduced 7%
- **ELSTER** electronic tax filing (mandatory)
- **DATEV** accounting standard integration
- **GoBD** compliance (digital record-keeping requirements)
- **SAP config:** Tax procedure TAXD, tax codes for Vorsteuer/Umsatzsteuer

## E-Invoicing
- **XRechnung** (mandatory for B2G since 2020)
- **ZUGFeRD** format (hybrid PDF + XML)
- EU e-invoicing directive compliance
- **Peppol** network participation

## Banking & Payments
- **SEPA** Credit Transfer (SCT) and Direct Debit (SDD)
- **DTAUS/DTAZV** legacy formats (being phased out)
- **EBICS** banking communication protocol
- **Payment format:** SEPA XML (pain.001, pain.008)
- **Bank statement:** MT940 / camt.053

## Date & Currency
- **Date format:** DD.MM.YYYY
- **Currency:** EUR (€)
- **Decimal notation:** 1.234,56
- **Fiscal year:** Calendar year

## Regulatory
- **GDPR** (Datenschutz-Grundverordnung / DSGVO)
- **GoBD** (Grundsätze zur ordnungsmäßigen Führung und Aufbewahrung von Büchern)
- **Handelsgesetzbuch (HGB)** — commercial code accounting
- **Bundesanzeiger** — annual financial statement publication
- **Kurzarbeit** rules for HR/payroll

## Key SAP Transactions
- RFUMSV00 (advance VAT return)
- SKAT (tax code maintenance)
- DMEE (payment medium format — SEPA XML)
